Workflows / 03 Run remote

talos-sky

Outposts for your coding agent.

talos-sky gives the agent on your laptop, Claude Code or Codex, an outpost on every machine you can reach over SSH: a rented GPU, a cloud VM, a lab server. Through it the agent runs commands and long jobs, copies files both ways, has cheap rules watch the logs, and sees renders, videos, 3D models and metrics as they are made.

  • v0.5
  • private preview
No keys on hosts
The outpost runs no model. Model calls leave from your laptop, with your agent's own login.
python3 is enough
No pip, no network and no repository access needed on the host.
Agent and terminal
Ten MCP tools, and a tsky command for each of them.
Survives sleep
Events from while the laptop was away arrive when it comes back.

How it works

The laptop opens every connection. On the host, the outpost keeps jobs, watches and an event log, and listens only on a private socket reached through SSH. Below is one background job, end to end.

What it does

Jobs
Run a command, or start a long one in the background and get a job id. Kill it, tail it, or let it finish while you are away.
Files
Copy files and folders both ways over one shared SSH connection per host. Nothing is overwritten unless asked.
Watches
Cheap rules on the host: a log line matching a pattern, a full disk, low memory. Each hit arrives with load, memory and GPU state.
Previews
Anything a job writes to preview/ reaches the agent: images, video, 3D models drawn from four sides, metrics as curves.
Remote viewers
Bring TensorBoard, Jupyter, Rerun, viser or a simulator page to a localhost URL through a tunnel that reconnects by itself.
Two modes
Operate, gated by your agent's permission prompts, or read-only: allowlisted inspection commands, no shell, no uploads.

Use it

Safety

  • The outpost runs no model, and tsky stores no credentials on either side.
  • Everything a host sends is treated as untrusted: capped, cleaned, and never able to approve a tool call.
  • The laptop opens every connection. The outpost listens only on a private Unix socket reached through SSH.
  • The preview board and tunnels listen on 127.0.0.1 only.
  • Copies unpack only regular files inside the target, and overwrite nothing unless asked.
  • Read-only mode is a guard rail, not a sandbox: rented machines get a low-privilege user and no long-lived credentials.

Limits and next

Limits today
Events reach Claude Code live through its research-preview channels; other agents read them with the events tool. Previews over 32 MiB are not fetched. Renting a GPU goes through your own provider CLI, after you confirm the offer.
