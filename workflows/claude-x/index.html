claude_x

Cheaper models as native Claude Code subagents.

claude_x is a drop-in launcher for Claude Code. It registers workers that run on a third-party model, DeepSeek today, as ordinary subagents. They appear in the agent panel, use Claude Code's own tools, permissions and hooks, and can be steered mid-run like any other subagent. The main agent stays on Claude.

  • private preview
Claude Code, unmodified
The official CLI, started with its own flags.
Main agent on Claude
Only the work you delegate goes to the cheaper model.

No files in ~/.claude. Run plain claude to stop.

How it works

claude_x starts a small gateway on your machine, then launches the official Claude Code pointed at it. Every model request passes through the gateway, which routes it by model name. Below is one delegation, end to end.

What it does

Native subagents
Workers come in through Claude Code's own agent definitions, not an MCP server, so permissions, hooks, the agent panel and steering mid-run all work as usual.
Private by default
Only a short list of headers is forwarded to the third party. Account identifiers and the memory index are removed, and a final scan refuses any request where one survives.
Workers stay workers
Workers cannot start subagents of their own, so a delegated task cannot fan out into more Claude work. Provider errors come back clearly marked and fail fast instead of retrying.
Real costs
Each worker request is written to a local ledger with its tokens and cost at the provider's prices, including cache reads and peak hours.

Use it

Guarantees

  • The gateway listens on 127.0.0.1 only and answers only requests that carry this session's random token.
  • Claude model names cannot be rerouted. They always go to Anthropic, unchanged.
  • The provider key is read per request, never written by claude_x, and sent only to its own provider.
  • A worker request in which any account identifier survives is refused and never sent.
  • Tools run on your machine, under Claude Code's own permission rules.
  • Nothing is installed into ~/.claude, and plain claude is untouched.

Limits and next

Limits today
Only Anthropic-compatible endpoints, and DeepSeek is the only provider tested. Claude Code's own cost display prices workers as a Claude model; claude_x --x-usage shows the real spend. Workers are reachable from the main session only.
