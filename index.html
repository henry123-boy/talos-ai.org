#!/usr/bin/env bash
set -euo pipefail
mkdir -p /logs/verifier /tmp/run
cd /testbed

# copy the hidden tests into the repository
while IFS= read -r relpath; do
  [ -n "$relpath" ] || continue
  case "$relpath" in
    /*|*..*) echo "unsafe test overlay path" >&2; exit 2 ;;
  esac
  mkdir -p "$(dirname "$relpath")"
  cp "/tests/test_files/$relpath" "$relpath"
done < /tests/test_files_manifest.txt

mapfile -t TARGETS < /tests/test_targets.txt
bash /tests/test_run.sh "${TARGETS[@]}" \
  > /logs/verifier/test_output.txt 2>&1
python /tests/_compute_reward.py

# tests/_compute_reward.py

pass_to_pass = read_manifest("pass_to_pass.txt")
targets = fail_to_pass + pass_to_pass

Data and environments for training agents.

Talos builds reinforcement-learning environments, trajectories and evaluations for teams training frontier agents. Tasks come from real open-source pull requests, computational science and physical simulation, and every one is graded by tests the agent never sees.

Contact us

What we build

Software engineering
Features and fixes rebuilt from real pull requests in open-source Python and Go projects, graded by fail-to-pass and pass-to-pass tests.
Scientific computing
Research problems with simulated instruments and measurement budgets, from Hamiltonian learning to quantum error correction, scored against a private ground truth.
Physical simulation
Tasks where agents write simulation and rendering code in Blender and MuJoCo, from rigid bodies to cloth, scored by comparing the result with reference physics and video.
Trajectories
Complete agent runs on every task, from the first command to the final patch, with the verifier's result attached.

Platform

Make everyone an AI trainer.

We are building talos-sky, the layer that links four things: data, models, benchmarks and sandboxes. Annotators and researchers submit work from their own agent, such as Claude Code or Codex. talos-sky runs it in a sandbox with the engines already installed, checks it by training models on it and scoring them on benchmarks, and ships only what passes.

Quality

Every task pins its environment and runs its verifier in a separate container without network access. Software tasks must fail on the base commit and pass with the reference patch, and existing tests must keep passing. Science tasks are scored from evidence the verifier checks itself, such as instrument logs, measurement budgets and certified numerical bounds, never from the agent's own report. Simulation tasks are scored by re-running the agent's scene in a clean container and measuring it against reference trajectories and renders.

Tasks ship in the Harbor format, with a task.toml, environment, tests and a reference solution for each one, and trajectories as JSON.
